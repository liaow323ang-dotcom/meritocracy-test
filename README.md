# Meritocracy Test · 优绩主义自测

21道生活情境题，六维雷达图与文字结果。纯 HTML、CSS、JavaScript，不需要构建、数据库或第三方接口。

## GitHub Pages 发布

将此压缩包解压后的文件上传到仓库根目录（不要上传压缩包本身）。在 Settings → Pages 中选择 Deploy from a branch，再选择 main 分支和 / (root)，保存。

网页会从 index.html 运行，所有静态资源均使用相对路径，支持 GitHub Pages 的项目子目录。

## 功能

支持手机作答、断点续答、回看改答、结果长图和文字报告下载。答案保存在访客浏览器本地。本版公开免登录，不含收款或激活码系统。

题目和解释为重新编写的内容。本问卷仅供自我观察与娱乐，未经心理测量学验证。
